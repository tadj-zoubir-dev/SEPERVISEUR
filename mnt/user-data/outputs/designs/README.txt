Put your graphic-design portfolio images in this folder, named:

  design-1.jpg
  design-2.jpg
  design-3.jpg
  design-4.jpg
  design-5.jpg
  design-6.jpg

(.png/.webp work too — just update the file extension in script.js.)

To add a new design: drop the file here and add one more line to the
`designs` array in script.js (search for "EDIT THESE LISTS").
